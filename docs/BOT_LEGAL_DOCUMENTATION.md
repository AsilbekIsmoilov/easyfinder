## Production oldidan majburiy to‘ldirish

1. Operatorning to‘liq yuridik nomi yoki YTT/F.I.Sh.
2. Rasmiy support email va pochta/yuridik manzil.
3. Ma’lumotlar serveri joylashgan davlat va hosting provayderi.
4. MySQL, Redis, media storage, backup va loglar uchun aniq retention muddatlari.
5. Foydalanuvchi ma’lumotini eksport/o‘chirish bo‘yicha ichki jarayon va javob muddati.
6. O‘zbekistonda shaxsga doir ma’lumotlar bazasini ro‘yxatdan o‘tkazish va lokalizatsiya talabi bo‘yicha yurist xulosasi.
7. Scrape qilinadigan kanallar bilan ruxsat/litsenziya yoki takedown jarayoni.
8. Brend nomi o‘zgarganda barcha hujjatlarda `TourFinder(Beta)` va `@turbozorbot`ni almashtirish.
9. Rus tilidagi yuridik tarjimani yurist bilan tekshirtirish.

## Hozirgi tizimda saqlanadigan user ma’lumotlari

- Telegram ID, ism, username, profil rasmi URL’i;
- first_seen va last_seen;
- Telegram chat ID va notification obunasi;
- ko‘rishlar va like’lar;
- comment, feedback va reply;
- qidiruvlar, davlat, kanal, manba, budjet va sanalar;
- tavsiya preference’lari;
- texnik server va reverse-proxy loglari.

## Muhim risklar

- Sun’iy intellekt (Anthropic Claude) yordamida ajratilgan ma’lumot 100% aniqlikni kafolatlamaydi.
- E’lon matni qayta ishlash uchun Anthropic API ga yuboriladi (AQSh). Bu yerga foydalanuvchining shaxsiy ma’lumoti emas, faqat ommaviy kanal posti ketadi — lekin bu Privacy Policy’da ochiq ko‘rsatilishi shart.
- Kanal commenti uchinchi tomon Telegram muhokamasida ommaviy ko‘rinadi.
- Hozir avtomatik data deletion endpointi yo‘q; so‘rov operator orqali bajariladi.
- Hozir kodda retention cleanup faqat muddati o‘tgan turlarga qo‘llanadi, user ma’lumotlariga emas.
- Privacy Policy’dagi ishlab chiqarish tafsilotlari operator tomonidan yakuniy tasdiqlanmaguncha hujjat draft hisoblanadi.
